# Bloom — pin copy for the quiet set

Five pins, each ready to paste. Link for all of them:

```
https://bloomgarden.study
```

The images carry this same URL, so copy and picture always agree.

Pinterest shows roughly the first 40 characters of a title in the feed and reads the
description for search, so the keywords are front-loaded on purpose. Hashtags barely
count on Pinterest any more; the words in the description are what get indexed.

## Posting notes

- **Space them out.** Posting all five at once splits impressions between them. A few
  days apart gives each one a clean read.
- **Lead with `quiet-free`.** It kills the two objections — cost and installing something —
  before anyone has to click.
- **Same link on all five**, so whichever one takes off still sends people to the same place.
- **Watch which hook wins, not which picture.** Three of the fifteen images use the day
  planner screen. If a garden or timer pin outperforms, that is a real signal about the
  hook rather than the screenshot.
